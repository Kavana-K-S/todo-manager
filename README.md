\# 📝 To-Do Manager



A full-stack To-Do Manager application built using React, Node.js, Express, and MongoDB.



\## 🚀 Features



\- Add new tasks

\- Edit tasks

\- Delete tasks

\- Mark tasks as completed

\- Set task priority: High, Medium, Low

\- Set due dates

\- Search tasks

\- Filter tasks

\- Clear completed tasks

\- Track total, pending, and completed tasks

\- Store tasks in MongoDB

\- Detect overdue tasks



\## 🛠️ Technologies Used



\### Frontend

\- React

\- JavaScript

\- HTML

\- CSS



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose
